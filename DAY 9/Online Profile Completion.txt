Online Profile Completion
If user has uploaded profile photo AND verified email AND filled all required fields, mark profile as “Complete”.
Otherwise, mark as “Incomplete”.

    photo= true

END FUNCTION


FUNCTION profile(photo,email,fields)
    IF profile == true AND email == true AND fields == true THEN
