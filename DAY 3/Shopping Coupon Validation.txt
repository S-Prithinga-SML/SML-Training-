Shopping Coupon Validation

A customer enters a coupon code.
If the code is valid and the purchase amount is greater than ₹3,000, apply discount.
Otherwise, no discount is applied


FUNCTION main()
    customercoupon="637ed"
    coupon={
        ["963fg"]
        ["637ed"]
    }
    purchaseamount=3500
    result=validatecoupon(customercoupon, coupon, purchaseamount)
    DISPLAY result
    END FUNCTION
